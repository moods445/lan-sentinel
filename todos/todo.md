## P0 · 本版遗留（不新增功能，只补验证与收尾）

- [ ] **24h 长稳观察**
      - 指标：server/agent RSS 波动 ≤10%、原始分区日增 ≤1.5GB、事件噪声（非真实故障的 open 数）
      - 方法：两台机保持运行，次日对比 `docker stats`、`metric_samples` 分区大小、`events` 清单
      - 验收：24h 内无 OOM、无分区暴涨、无规则抖动导致的反复开/关
- [ ] **浏览器视觉验收**
      - 主机墙 1440/768 两档、空状态、离线主机、事件为空、长主机名不溢出
      - 验收：无 JS 报错、无横向滚动、5s 刷新不闪烁
- [ ] **真实交换机 SNMP 验证**
      - 多 ifIndex、`ifOperStatus` 掉线、计数器回绕、设备不支持 `hrProcessorLoad` 时只跳过不落 0
      - 验收：交换机断一口，`if_oper_up:<idx>` 归 0 且触发告警；恢复后关闭
- [ ] **本机磁盘清理**
      - 根盘已 89%，其中构建缓存约 450MB
